Cofrin

O Cofrin é um aplicativo pessoal de finanças, para computador e Android, feito para uso do próprio autor.

Os dados ficam no aparelho. O Google Drive é usado só para levar as mudanças de um aparelho para o outro: o app acessa apenas os arquivos que ele mesmo cria no Drive de quem o usa (permissão drive.file).
